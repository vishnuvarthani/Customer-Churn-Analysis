# Customer-Churn-Analysis
This project analyzes telecom customer data to understand the main reasons for customer churn and predict whether a customer is likely to leave.

## What I Did

- Cleaned and prepared the dataset
- Performed Exploratory Data Analysis (EDA)
- Analyzed customer churn patterns
- Built Logistic Regression, Decision Tree and Random Forest models
- Compared model performance

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Result

Logistic Regression performed best with around **80% accuracy**.
